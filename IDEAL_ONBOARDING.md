# Cisco Webex Connector — Ideal Onboarding Flow

1. Пользователь открывает коннектор в Imperal Cloud.
2. Вводит свои учетные данные (API Token / JWT / OAuth) в левый сайдбар.
3. Коннектор проверяет валидность токена вызовом к API сервиса.
4. При успешной проверке соединение активируется и доступно для сценариев автоматизации.
