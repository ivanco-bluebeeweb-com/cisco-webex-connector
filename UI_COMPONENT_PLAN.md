# Cisco Webex Connector — UI Component Plan

- **Left Sidebar**: `slot="left"`, растянут на всю ширину (`align="stretch"`).
- **Form Inputs**: Четкие лейблы `variant="label"` и контекстные `placeholder`.
- **Help Modal**: Модальное окно `_help_modal()` с инструкцией по подключению.
- **Settings Screen**: `panels_settings.py` внизу сайдбара для управления подключенными аккаунтами.
